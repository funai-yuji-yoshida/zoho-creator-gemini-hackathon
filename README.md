# Gemini × Zoho Creator
# AI業務改善アプリ作成ハッカソン

GeminiとZoho Creatorを組み合わせて、
「自分たちの業務を改善するアプリ」をAIと一緒に作るハッカソンです。

プログラミングの知識は必須ではありません。

大切なのは、

> 「AIに何を作らせるか」ではなく、
> 「自分たちの仕事をどう変えたいか」

を考えることです。

---

## 🚀 最初にやること

初めて参加する方は、次の順番で進めてください。

### ① 参加者向け手順書を読む

`01_参加者手順書`

にある手順書を最初に確認してください。

GeminiのGem（カスタムアシスタント）の作成方法から、
Zoho CreatorへのDSファイルのインポートまで説明しています。

### ② Gem①を作成する

`02_Gemプロンプト/Gem①_Ver.2_完成版.md`

を使用します。

Gem①は、

**「新しい業務アプリを設計し、Zoho Creator用のDSファイルを生成するGem」**

です。

### ③ Gem②を作成する

`02_Gemプロンプト/Gem②_Ver.2_完成版.md`

を使用します。

Gem②は、

**「Gem①で作成した既存アプリに、ワークフローやレポートなどの機能を追加するGem」**

です。

### ④ ナレッジファイルを登録する

Gemごとに使用するナレッジファイルが異なります。


#### Gem②

`04_Gem②ナレッジ`

```text

```

# 🤖 Gem①とGem②の違い

| | Gem① | Gem② |
|---|---|---|
| 役割 | 新規アプリ作成 | 既存アプリ改善 |
| 主な対象 | フォーム・フィールド | ワークフロー・レポート |
| 最初に必要なもの | 業務アイデア | Zoho Creatorから出力したDS |
| 出力 | 新しいDSファイル | 機能追加したDSファイル |
| 使用ナレッジ | T1・T2・T3 | T1・T2 |

# ⚠️ 最重要ルール

## 1. 仕様確認前にDSを生成しない

Gem①では、

**業務ヒアリング → アプリ構成案 → 人間による確認**

の順番で進みます。

構成案を確認して、

> 「OK」

となってからDSファイルを生成します。

AIに任せきりにせず、**人間が業務設計を確認すること**が重要です。

## 2. フォームやフィールドを変更したい場合

Gem②では、既存のフォーム・フィールド構造を維持することを基本としています。

フォームやフィールドそのものを変更したい場合は、

**Gem②で無理に変更せず、Gem①に戻って設計を見直してください。**

## 3. Gem②には最新のDSを渡す

Zoho Creatorで実際に動作確認した後、

**現在のアプリから最新のDSファイルをエクスポート**

してGem②に添付してください。

古いDSを使わないことが重要です。

# 💡 どんな業務をアプリにする？

特別なテーマを考える必要はありません。

普段の仕事を思い出してください。

例えば、

- Excelで管理している
- 紙に記録している
- メールで申請している
- 毎回同じ内容を入力している
- 担当者によってやり方が違う
- 過去の情報を探すのに時間がかかる
- 誰かに聞かないと分からない
- 集計や報告書を毎回作っている

こうした業務は、アプリ化の候補になります。

---

# 🧩 例えばこんなアプリ

### 顧客先訪問記録アプリ

営業担当者が顧客を訪問した際に、

- 顧客名
- 訪問日
- 担当者
- 面談内容
- 次回アクション

などを記録します。

まずGem①に業務内容を伝え、
アプリの構成を一緒に考えてみましょう。

その後、Zoho Creatorにインポートして実際に動かします。

さらにGem②を使って、

- 自動通知
- 自動入力
- 条件チェック
- 一覧レポート

などを追加できます。

# 🛠 困ったとき

### DSファイルが生成されない

Gem①との会話がまだ「アプリ構成の確認」の段階ではないか確認してください。

構成案を確認して「OK」と伝えてからDS生成に進みます。

### Zoho Creatorにインポートできない

DSファイルが途中で切れていないか確認してください。

また、Gem①が生成したDSファイルをそのまま使用してください。

### Gem②がアプリを理解できない

Gem②には、

**Zoho Creatorからエクスポートした最新のDSファイル**

を添付してください。

### フォームやフィールドを変更したい

Gem②ではなくGem①に戻ってください。
